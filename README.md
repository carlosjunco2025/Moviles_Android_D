# TECSUP Fit - Gestión de Clases

Aplicación móvil nativa en Kotlin y Jetpack Compose para Lab 05.

## Requisitos Funcionales
- Catálogo dinámico con filtros.
- Detalle de clase y selección de horario.
- Confirmación de reserva.

## Requisitos Técnicos
- Kotlin, Jetpack Compose, Material3, Navigation Compose.
